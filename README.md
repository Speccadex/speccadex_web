# Speccadex – Web

A Speccadex webes felülete: PC-konfigurátor és közösségi platform, ahol a felhasználók virtuálisan összeállíthatják a gépkonfigurációjukat, elmenthetik, és megoszthatják a fórumon.

## Tech stack
- React
- Tailwind CSS

- speccadex-mobile (Android)
